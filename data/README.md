# Data

The dataset used in this project contains daily retail demand and inventory information across multiple stores and products.

## Dataset Source

Link: https://www.kaggle.com/datasets/atomicd/retail-store-inventory-and-demand-forecasting 

The dataset is licensed under the **Apache License 2.0**.

## Main Dataset Characteristics

- 76,000 observations
- 5 stores
- 20 products
- 5 product categories
- Daily data from January 2022 to January 2024

Main variables include:

- Demand
- Price
- Discount
- Promotion
- Inventory Level
- Units Sold
- Units Ordered
- Seasonality
- Weather Condition
- Competitor Pricing
